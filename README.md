# HARDER, BETTER, FASTER, STRONGER 的 ParaTranz！

ParaTranz-tools 是一个给 ParaTranz 词条编辑页面用的小脚本，补上几个平时校对时不太顺手的地方。

目前有这些功能：
- **插件管理页**：自动收纳其他脚本加在右侧的页签，打开各自的面板和配置。插件提供版本和更新地址后可提示更新；支持接入的插件还能按项目排除、使用独立设置。未接入的脚本会注明限制，收纳入口不会停止运行。
- **疑问分组以及管理**：疑问现在可以设置分组标注疑问类别，安装该插件的成员可以共享分组信息。支持管理。
- **保存并审核**：保存当前修改，直接标记为“已审核”（绿色勾）。原生的上一个选项改为“保存并检查”，用于“已检查”（笑脸）。
   - **检查、审核分开显示**：没有待保存修改时，蓝标的主按钮是浅绿色“检查”，点后变笑脸；笑脸的主按钮是绿色“审核”，点后变绿色勾。
- **代码悬浮注释**：代码也能读取术语表里的说明，鼠标移上去就能看，不加下划线。
   - **格式标签说明**：斜体、加粗、下划线、颜色等标签自带说明，尖括号和方括号两种写法都支持。

一些小小的修复与改进:
- **修复注释 @ 补全**：点击下面的候选用户名时，避免列表提前消失、名字填不进去。
- **分页修复与记忆**：记住当前页码和每页条数；列表加载结束后仍与设置不符时，最多重新读取一次。不同文件和筛选条件分别记忆。

审核和检查需要当前项目的所有者或管理员权限，每次只处理当前词条。

## 安装

先装好 Tampermonkey（油猴），再 [点击这里安装脚本](https://raw.githubusercontent.com/AshoreFall/ParaTranz-tools/main/dist/paratranz-review-shortcuts.user.js)。安装后刷新 ParaTranz 页面就能用了。
