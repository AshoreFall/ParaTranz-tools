# ParaTranz-tools

ParaTranz-tools 是一个给 ParaTranz 词条编辑页面用的小脚本，补上几个平时校对时不太顺手的地方。

目前有这些功能：

- **空译文也能审核**：保存菜单里增加“标记为已审核”，有译文修改时会一起保存。
- **保存并审核**：保存当前修改，直接标记为“已审核”（绿色勾）。原生的上一个选项改为“保存并检查”，用于“已检查”（笑脸）。
- **检查、审核分开显示**：没有待保存修改时，蓝标的主按钮是浅绿色“检查”，点后变笑脸；笑脸的主按钮是绿色“审核”，点后变绿色勾。
- **修复注释 @ 补全**：点击下面的候选用户名时，避免列表提前消失、名字填不进去。
- **分页修复与记忆**：记住当前页码和每页条数；列表加载结束后仍与设置不符时，最多重新读取一次。不同文件和筛选条件分别记忆。
- **代码悬浮注释**：代码也能读取术语表里的说明，鼠标移上去就能看，不加下划线。
- **格式标签说明**：斜体、加粗、下划线、颜色等标签自带说明，尖括号和方括号两种写法都支持。

审核和检查需要当前项目的所有者或管理员权限，每次只处理当前词条。

## 安装

先装好 Tampermonkey（油猴），再 [点击这里安装脚本](https://raw.githubusercontent.com/AshoreFall/ParaTranz-tools/main/dist/paratranz-review-shortcuts.user.js)。安装后刷新 ParaTranz 页面就能用了，已经装过的直接更新原脚本。

保持油猴自动更新开启，以后仓库发布新版时就能收到更新。改名安装后，如果管理面板里同时出现旧名“ParaTranz 直接标记已审核”和新名“ParaTranz-tools”，关闭旧的那份，保留新的一份启用。

## 平时怎么用

安装后照常打开 ParaTranz。保存下拉菜单里，上面的“保存并检查”是笑脸，下面的“保存并审核”直接打绿色勾；“标记为已审核”也直接打绿色勾，允许译文为空。注释里输入 `@` 和名字的一部分，再点候选人即可。

新增的审核选项只在能使用时显示，不能使用时直接隐藏。

分页功能自动生效。例如每页 800 条、正在第 3 页，刷新后会恢复这个位置。加载异常时，脚本会先检查是否有未保存的译文，保留当前草稿。

想给代码写说明，就照常添加术语：原文填代码，译文也填同一段代码，再把说明写进“额外的说明”。例如原文和译文都填 `⟦WhoLeads:01⟧`，说明填“根据当前领路人替换”。打开包含这段代码的词条，把鼠标停在原文里的代码上就能看到。普通术语仍保留原来的下划线。

`<i>`、`[i]` 是斜体，`<b>`、`[b]` 是加粗，`<u>`、`[u]` 是下划线，`<color=#ff0000>`、`[color=red]` 是颜色，结束标签也有说明。另外支持 `em`、`strong`、删除线、字号、字体、上下标和换行。术语表里有你写的说明时，会优先显示你的内容。悬浮说明显示在原文区。

更新的过程是：**修改脚本 → 上传 GitHub → 油猴检查到更高版本 → 下载新版 → 刷新 ParaTranz**。GitHub 存放文件，油猴负责安装和更新，脚本在 ParaTranz 页面运行。只修改桌面文件，还不会更新到浏览器里。

## 以后怎么改

完整代码在 `dist/paratranz-review-shortcuts.user.js`，每个功能前都有中文注释，找到对应位置修改就行。

`dist/paratranz-review-shortcuts.meta.js` 是给油猴检查版本用的小文件。发布新版时提高两个文件里的 `@version`，一起上传，文件名和更新链接保持原样。
